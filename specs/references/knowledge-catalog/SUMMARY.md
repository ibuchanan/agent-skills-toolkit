## Knowledge Catalog overview

The vendored Knowledge Catalog repository presents tools, agents, and samples for context management, enrichment, and retrieval solutions around Google Cloud Knowledge Catalog, formerly Dataplex. Its product description frames Knowledge Catalog as an AI-powered data catalog and metadata-management platform that provides a dynamic knowledge graph for structured and unstructured data.

The repository is organized around demonstrations and supporting tooling, including `samples/`, `toolbox/`, and `okf/`. The `okf/` directory contains the Open Knowledge Format v0.2 specification and reference implementation material; load [the dedicated OKF reference map](../open-knowledge-format/SUMMARY.md) for normative bundle-format guidance.

The repository states that its solutions are Apache-2.0 licensed and that the repository and its contents are not an official Google product.
